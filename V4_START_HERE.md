# V4 Progression — starten

1. ZIP vollständig entpacken und den **gesamten Inhalt** in den Root des bisherigen GitHub-Repositories übernehmen. `index.html`, sieben JavaScript-Dateien, drei CSS-Dateien und `assets/` gehören zusammen.
2. GitHub → Settings → Pages → **Deploy from a branch → main → /(root)**. Kein Buildsystem erforderlich.
3. Nach abgeschlossenem Deployment den bestehenden HTTPS-Spiel-Link in Safari öffnen und das iPhone quer halten. Keine Veröffentlichung wurde in diesem Durchlauf durchgeführt.
4. Drei Starter wählen → Gruppe bilden → leichte Quest → auswerten → Belohnung übernehmen. Danach Gilden-Level/XP im Kopfbereich antippen, Mitgliederstärke und Lagervergleich prüfen. Freie Items und Tränke lassen sich verkaufen. Schwere Quests besitzen eine Warnung, kein Power-Verbot.
5. Neue Angebote am Questbrett ersetzen nur nicht gestartete Angebote. Dadurch können weitere leichte Quests gespielt werden, während schwierigere Ziele noch außer Reichweite sind.
